# 嵌套表格 Nested Canvas Tables

在 Obsidian 原生 `.canvas` 画布中摆放可编辑表格卡片，单元格内可递归创建子表格。

- 表格卡片是普通 Markdown 文件，内含 `nctable` 代码块；画布只用标准 `file` 节点，不碰 Canvas 内部接口。
- 表格数据存为 Vault 内独立 JSON 文件（默认根目录 `NestedTables/`，可在设置中修改），代码块以 Vault 绝对路径指向数据文件，移动画布不断链。
- 编辑自动保存（防抖 + `Vault.process`）；数据文件损坏、缺失或被外部修改时停止写入并给出可读提示，绝不静默覆盖。
- 阅读优先（OneNote 式文档表格）：列名是可编辑文字（默认「列 N」，可改成「病史/症状/…」），表头用主题底色填充；无标题栏、无常驻按钮——增删行列、子表等操作控件默认隐藏，悬停或键盘聚焦到对应表格/行/列/单元格时才浮现，深层嵌套也不会变成按钮墙；折叠的子表保留一个小标记便于发现。
- 嵌套子表是带自己表头的真实表格，可逐层递归；旧版 `col_id` 表头数据在加载时自动迁移为「列 N」。
- 单元格支持 Markdown 行内语法：`==荧光==`、`**加粗**`、`*斜体*`、`~~删除~~`、`` `代码` ``，**可互相嵌套**（如加粗内再变色），并支持 `![[图片]]` / `![alt](路径)` 图片渲染（缺失图片显示占位而非破图）。双态显示——聚焦编辑时看源码，失焦即渲染（自研递归解析器，深度封顶、颜色 span 白名单、createElement/textContent 安全渲染，无 XSS）。
- 右键单元格弹出格式菜单：加粗/斜体/荧光/删除/代码（**包裹当前选区**，选区在弹菜单瞬间捕获，真实点击不丢；重复点同一格式解除包裹；无选区则在光标处插入成对标记）、文字颜色（红橙绿蓝紫/默认，**只染选中文字**——选区包裹 inline 颜色 span；无选区才整格）、底纹（五色晕/无）、插入图片…、清除格式、复制、粘贴。
- 内容自适应：表格宽高随内容收缩，不拉满卡片；**右键菜单「适应容器宽度」一键切换适应模式**——根表撑满卡片、嵌套子表撑满父格，画布外框拉大时实时跟随（`fitWidth` 持久化，再点一次回到随内容收缩；已拖拽列宽在适应模式下保留为 px 提示，其余列均分剩余宽度）。操作控件（工具栏、行×/列×、+子表、折叠）绝对定位悬浮、悬停才浮现，静止态不占空间。**按钮永不遮挡文字**：悬停/聚焦时单元格右侧让出预留槽（padding 过渡），×/+子表 只落在槽内；折叠/子表工具栏落在子表区顶部预留槽；让槽条件与控件浮现条件一致，可见即不压字；折叠态单元格保留常驻右槽。
- 行高列宽自由拖拽：表头右缘拖列宽、行底缘拖行高（定高内容盒 + 内部滚动），双击手柄恢复该行/列自适应；尺寸持久化于 `columnWidths`/`rowHeights`（增删行列自动对齐，全 null 回收）。
- 图片入格：截图直接粘贴、拖拽图片文件入格、或右键「插入图片…」；附件存 `<根目录>/attachments/`，源码插入 `![[…]]`，失焦渲染缩略图。
- 一键新建：左侧栏表格图标（ribbon）、命令「一键新建嵌套表格」、编辑器右键「插入嵌套表格」——画布内向右追加节点、笔记光标处插入代码块、其余场景新开卡片并打开。
- 列头同样可右键设置文字颜色/底纹/清除/复制/粘贴（存于与列等长的 `columnStyles`，增删列自动对齐）；列头不渲染 markdown，故菜单不含包裹项。右键嵌套子表的表头/工具栏只会作用于该子表自身，不会穿透误染父单元格。
- 键盘：`Tab`/`Shift+Tab` 跨格移动焦点，`Esc` 退出编辑，`Mod+B`/`Mod+I` 加粗/斜体选区（聚焦期间以 Scope 置顶接管，失焦即还原，笔记与编辑器不受影响）。
- **Editing Toolbar 适配**：画布内其工具栏的加粗/斜体/删除线/高亮/清除文本格式按钮直接作用于单元格选区（命令层接管 + 选区偏移追踪，按钮夺焦不丢选区）；普通笔记里仍走原命令，行为零回归。
- 新手友好：首次启用自动打开示例画布并跑 10 步引导（高亮环 + 说明卡，`Enter` 下一步、`Esc` 跳过、「不再显示」同时关闭引导与提示条）；表格上方有一次性渐隐提示条（6s）。命令「使用引导」「打开使用示例」可随时重看；设置页可开关「显示操作提示」。

## 命令

- **一键新建嵌套表格**（ribbon 图标 / 命令 / 编辑器右键「插入嵌套表格」）：画布内→右侧追加表格节点；Markdown 编辑器→光标处插入代码块；其余→新建卡片并打开。
- **新建带表格的画布**：创建表格卡片 + JSON 数据 + 合法 `.canvas` 并打开。
- **新建表格卡片**：只创建卡片与数据文件，用 Canvas 自带的「添加文件」或拖放放入现有画布。
- **使用引导**：重新打开示例画布并播放新手引导。
- **打开使用示例**：打开（必要时创建）含嵌套子表与格式示例的示例画布。

## 限制（MVP）

- 单元格支持上述五种行内 Markdown（可嵌套）+ 选区颜色 span + 图片；列头支持颜色/底纹但不渲染 Markdown；无公式、合并单元格、排序、块级富文本（标题/列表/链接等不解析）。
- Editing Toolbar 仅接管与单元格能力对应的五个命令（加粗/斜体/删除线/高亮/清除格式）；其余按钮（标题/列表/下划线等块级或 unsupported 格式）在格内仍不生效，笔记内不受影响。
- 移动端未实机验证（引导与右键菜单按桌面设计）。
- 数据文件被手动改名后路径失效，显示可读错误（不自动跟踪）。

## 验收（独立测试库实机，CDP 驱动）

七条验收标准均已实机通过：

1. 构建加载、两条命令正常（「新建带表格的画布」生成标准 `file` 节点 `.canvas` 并打开；「新建表格卡片」生成 md+json）；设置页「数据根目录」可改、持久化生效并影响命令输出。
2. 原生 Canvas 打开文件卡片即可编辑表格。
3. 三层嵌套（单元格→子表→孙表）创建、折叠/展开正常。
4. 关闭重开后数据完整（嵌套层级、文本、行列数均持久化）。
5. 画布平移/缩放/节点移动正常；在表格内输入、点击控件不会误拖节点（全程断言节点位移不变）。
6. 数据文件损坏 / 缺失 / 版本不支持时显示可读中文错误，绝不覆写或新建文件（逐字节比对确认）。
7. 禁用插件后数据与画布文件保留，重新启用正常。

已知限制：节点缩放手柄属 Canvas 原生 chrome（仅选中态出现，位于代码块外），自动化难以触发选中态，resize 列为手动验收项；插件本身不影响该原生行为。详见 `踩坑.txt`。
